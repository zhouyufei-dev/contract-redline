## 2. 关于"文件扫完即删"这句话 —— 先验证，再写上

这句话不是照抄，是**跑代码验过的**。`tools/verify_upload_disposal.py` 做的事：

1. 监听所有临时目录的创建；
2. 用 `fake_contract_01.docx` 的字节走一遍网页真实调用的 `analyze_upload()`；
3. 检查那个临时目录是否已被删除、LLM 缓存目录有没有新增文件。

实测结果：

```
cards produced        : 20
temp folders created  : 1
   contract-redline-lsz2rvgc  still exists = False
leftover temp folders : []
llm cache grew        : no
VERDICT: file removed from disk after the scan
```

**准确表述**：文件落在服务器临时目录，扫描结束（含出错）必删；网页路径传了 `use_cache=False`，所以 LLM 缓存不会留下任何条款原文。你自己浏览器里那份上传副本，在你关掉/刷新标签页前仍然存在——这是浏览器行为，不是我们的存储。

## 5. 老实说：哪些没验到

- **桌面/手机的实际观感没截图验过。** 这台机器上 Edge 的无头模式截不出图（会挂到已运行的实例上直接退出），沙箱浏览器又禁止访问 `127.0.0.1`。我改为做了结构化校验：括号配平、640px 断点里只允许改字号/行高/上边距、没有任何固定宽度会撑破 390px 屏幕。**像素级的"好不好看"只能你亲自看一眼。**
- 线上 `contractredline.io` 我只确认了外壳返回 200；文案在 Streamlit 应用里，推送后云端要重新部署 1–2 分钟才生效。
- 真实刷卡闭环未复测（见上）。
