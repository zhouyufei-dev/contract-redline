# 03 · 测试合同（Fake Contract）说明与标准答案

> 文件：
> - `data/samples/fake_contract_01.docx` ← 第 3 步解析器用的就是它
> - `data/samples/fake_contract_01.txt` ← 同一份内容的纯文本，便于搜索核对
>
> 合同主体全部虚构（Northwind Retail Group, Inc. vs. Alex Rivera / Rivera Studio），
> 不含任何真实公司或个人信息，可以随便分享、随便用。

---

## 一、这份合同是干什么用的

两个用途：

1. **第 3 步**：验证解析器能不能把 DOCX 读成干净的文字。
2. **第 4 步以后**：验证规则抓得准不准。**这是重点** —— 一份"标准答案"能让你在改正则的时候立刻知道自己是修好了还是改坏了。

## 二、埋了哪些坑（标准答案）

### 2.1 应该被抓出来的（正向命中）

| 条款位置 | 原文关键片段 | 应命中 | 命中的关键词 |
|---|---|---|---|
| 1.1 | `including but not limited to ... and such other services as Client may reasonably request from time to time` | **R06** | `including but not limited to` / `from time to time` |
| 1.2 | `at no additional cost` | **R07** | `at no additional cost` |
| 2.2 | `within sixty (60) days of the invoice date` | **R01** | `sixty (60) days` ← 注意"数字 + 括号数字"双写形态 |
| 2.3 | `upon Client's final acceptance` / `Client is satisfied, in Client's sole discretion` / `Deemed accepted until Client issues written acceptance` | **R02** | `upon ... acceptance` / `sole discretion` / `satisfied` |
| 2.4 | `after Client's receipt of payment from the end client` | **R03** | `receipt of payment from` / `end client` |
| 2.5 | `Client may set off against any amount` | **R04** | `set off` |
| 3.1 | `unlimited revisions ... until Client is satisfied ... as many times as necessary` | **R05** | `unlimited revisions` / `as many times as necessary` |
| 4.1 | `assigns ... all right, title and interest ... including all concepts, drafts, sketches, and unused directions ... in perpetuity` | **R08** | `assign all right, title and interest` / `unused` / `in perpetuity` |
| 4.2 | `work made for hire` | **R08** | `work made for hire` |
| 4.3 | `waives ... any moral rights` | **R09** | `moral rights` + `waive` |
| 4.4 | `shall not display ... in any portfolio ... without Client's prior written consent` | **R09** | `shall not display` / `portfolio` / `prior written consent` |
| 4.5 | `sublicense and resell ... train, fine-tune ... generative artificial intelligence models` | **R10** | `sublicense` / `resell` / `train` / `machine learning` |
| 5.1 | `error-free, free from defects, fit for Client's particular purpose` | **R20** | `error-free` / `free from defects` / `fit for ... particular purpose`（`compliant with all applicable laws` **故意不抓**，见 D-014） |
| 6.1 | `indemnify, defend and hold harmless ... any and all claims ... including reasonable attorneys' fees` | **R11** | `indemnify, defend and hold harmless` / `any and all claims` |
| 6.2 | `apply without limitation as to amount, duration, or number of claims` | **R12** | `without limitation as to amount` |
| 7.2 | `terminate ... at any time, for any reason or for no reason ... without further obligation or payment of any kind` | **R13** | `terminate` + `at any time` / `without further obligation` |
| 8.1 | `shall not directly or indirectly provide services similar to ... competitor ... twelve (12) months` | **R14** | `non-competition` / `competitor` / `directly or indirectly` |
| 8.2 | `shall not, directly or indirectly, solicit, engage, or accept work from any client ...` | **R15** | `solicit` / `directly or indirectly` |
| 9.1 | `whether or not marked as confidential` | **R19** | `all information` + `whether or not marked` |
| 9.2 | `survive in perpetuity and shall continue indefinitely` | **R19** | `perpetuity` / `indefinitely` |
| 10.1 | `Time is of the essence` | **R18** | `time is of the essence` |
| 10.2 | `liquidated damages of five hundred dollars ($500.00) per day` | **R18** | `liquidated damages` / `per day` |
| 11.2 | `binding arbitration administered in Wilmington, Delaware` | **R17** | `arbitration` |
| 12.1 | `Client may modify these terms at any time ... continued performance constitutes acceptance` | **R16** | `modify these terms at any time` / `continued performance constitutes acceptance` |

**覆盖率：20 条规则全部命中；这份假合同上一共出 24 张牌，对应 24 个条款——一句一牌。**
（R08 在 4.1 / 4.2、R09 在 4.3 / 4.4、R18 在 10.1 / 10.2、R19 在 9.1 / 9.2 各出两张，
因为那是**两句**要分别划掉的话，不是同一件事被报了两遍。）

5d 对这张表做了四处修正，都记在 D-014：

1. **11.1 不报。** `governed by the laws of the State of Delaware` 是商业合同里几乎必然出现的
   准据法条款，单独看它不会让自由职业者多付一分钱，也改变不了他能不能起诉——把它做成卡片，
   等于每份上传都附一张用户无法执行的牌。"异地管辖"的杀伤力由 11.2（仲裁地 Wilmington）承载，
   那一句才决定"你得去哪儿、花多少钱"。
2. **11.3 不报。** `The prevailing party ... shall be entitled to recover its reasonable
   attorneys' fees` 是**双向**写法（谁都可能是胜诉方），只要写成单向式的"客户可追偿"才报。
3. **11.4 不报。** `Each Party waives any right to a trial by jury` 是双向弃权，标准商业写法，
   而且在仲裁条款下本来就用不上。只有单向弃权（只约束你）才报。
4. **5.1 只报半句。** `error-free` / `free from defects` / `fit for Client's particular
   purpose` 照报；`compliant with all applicable laws` **不报**——那几乎是每份合同都有的一般性
   守法承诺。

5c 还做过两处修正，记在 D-013：

1. **6.2 从 R11 改判给 R12。** 6.1 是"赔偿承诺本身太宽"，6.2 是"这个承诺没有
   金额上限"——两个条款、两个不同的问题，分给两条规则各出一张卡才对。若都算
   R11，6.2 就会同时被两条规则命中，违反"同一句子不被两条规则重复报"。
2. **R12 仍然只做"正向形态"。** 本期它命中 6.2，是因为合同把"无上限"写在了明面上
   （`without limitation as to amount`）。真正的"全文找不到责任上限"这种**缺失
   形态**依然不做（D-004），第二批补。

> 所以这张表**不能**被读成"报告说这份合同是安全的"。缺失检测还没上场——这正是
> D-004 要求报告措辞只能写"在你上传的文本里，这 20 条规则没有命中"，绝不能写
> "没有重大问题，可以签"。

### 2.2 故意埋的"否定句陷阱"（**不能**报红）

这是这份合同最值钱的地方。两句结构上很像风险，但语义相反：

| 条款 | 原文 | 为什么不能报 |
|---|---|---|
| **2.6** | `Client shall **not** be obligated to pay interest ... Contractor **waives** any statutory late fee` | 含 `late fee` / `interest`，但语义是"客户不用付逾期利息"——**对自由职业者不利，但不是 R18 的罚款**。若被 R18 命中，属误报。 |
| **2.7** | `Contractor **may suspend work** if any undisputed invoice remains unpaid for more than thirty (30) days` | 含 `thirty (30) days`，语义是"你有权停工"——**这是对你有利的保护条款**。若被 R01 当成"付款周期 60 天"一类命中，属误报。 |
| **3.2** | `Notwithstanding Section 3.1, Client shall **not** request unlimited revisions to Deliverables that have been formally approved` | 含 `unlimited revisions`，但前面有 `shall not` + `Notwithstanding`——**必须降级为"需复核"或直接忽略**。 |
| **6.3** | `Contractor shall **not be liable** for any loss arising solely from materials ... supplied by Client` | 含 `not be liable`，实际是**对你有利的责任豁免**。R11 绝不能命中。 |
| **7.3** | `Contractor may terminate only in the event of Client's uncured material breach` | 有 `terminate`，但对你没有不利（你的终止权受限，但这句本身不是坏条款）。 |
| **11.1** | `governed by the laws of the State of Delaware` | 准据法条款，每份商业合同都有；单独看它不改变你的处境。**R17 不报**（D-014）。 |
| **11.3** | `The prevailing party ... shall be entitled to recover its reasonable attorneys' fees` | **双向**律师费——谁都可能是胜诉方。只在单向写法（只写客户能追）时才报。 |
| **11.4** | `Each Party waives any right to a trial by jury` | **双向**弃权，标准商业写法，仲裁条款下本来也用不上。 |

**验收标准：这 8 句，一条都不能报成"致命/严重"风险。**
如果报了，说明否定窗口（negation window）没写对——这是第 4 步的核心工作量。

### 2.3 应该"什么都不报"的条款（干净条款）

以下条款写得正常，用来测**误报率**：

- 1.3 Change Orders（有变更单机制，正常）
- 2.1 Fees（正常）
- 6.3 Client Materials（对你有利）
- 7.1 Term（正常）
- 7.4 Survival（正常）
- 12.2 Assignment（对你不利——你不能转让，客户可以自由转让。属 X02 候选，**本期不报**，符合预期）
- 12.3 / 12.4 / 12.5 Entire Agreement / Severability / Force Majeure（标准样板条款）

## 三、怎么用这份"标准答案"

第 4 步写完前 3 条规则（R01 / R02 / R05）之后，跑一次，然后对表：

```
预期：R01 命中 2.2；R02 命中 2.3；R05 命中 3.1
禁止：R05 命中 3.2（否定句陷阱）
```

三行都对上，才继续写剩下的 16 条。**每加一条规则，就重跑一次全表**——这叫回归测试，
是防止"修好一个、弄坏两个"的唯一办法。

## 四、第 4 步实测结果（3 条规则）

跑的命令：

```powershell
.\run.ps1 data/samples/fake_contract_01.docx -Scan -ShowSuppressed
.\run.ps1 data/samples/fake_contract_01.pdf  -Scan
.\.venv\Scripts\python.exe tools\test_rules_step4.py
```

| 预期 | 实测 | 结果 |
|---|---|---|
| R01 命中 2.2 | R01 → 2.2，抓到 `sixty (60) days`，数值 60 | ✅ |
| R02 命中 2.3 | R02 → 2.3，抓到 `upon Client's final acceptance` | ✅ |
| R05 命中 3.1 | R05 → 3.1，抓到 `unlimited revisions` | ✅ |
| R05 **不**命中 3.2 | 3.2 被否定闸门拦下 | ✅ |
| 2.4（15 天）不报 | 未报 | ✅ |
| 2.7（停工保护条款）不报 | 未报 | ✅ |
| 2.6（不付逾期利息）不报 | 未报（R18 未实现） | ✅ |
| 6.3（`shall not be liable`）不报 | 未报（R11 未实现） | ✅ |
| 4.4（作品集 `sole discretion`）不报 | 未报 | ✅ |
| 干净合同零误报 | 0 条 | ✅ |

总计 51 项自动检查全部通过。DOCX 与 PDF 结果完全一致。

**第一次跑出来时抓到 2 个误报，已修**（详见 `docs/04-第4步-匹配引擎说明.md`）：

2. R02 打到了 4.4 的 `sole discretion`（作品集条款被当成验收条款）。

## 五、第 5 步最终实测：20 条规则 vs 假合同（5d 收尾）

一条命令跑全集：

```powershell
.\run.ps1 data/samples/fake_contract_01.docx -Scan     # 假合同，看 24 张牌
.\.venv\Scripts\python.exe tools\test_rules.py          # 297 项自动检查
.\.venv\Scripts\python.exe tools\stress_clean.py        # 74 句干净样板，测误报
```

| 指标 | 结果 |
|---|---|
| 20 条规则是否全部命中 | ✅ 全部命中，24 张牌，顺序与合同章节一致 |
| 命中条款 | 1.1 / 1.2 / 2.2 / 2.3 / 2.4 / 2.5 / 3.1 / 4.1 / 4.2 / 4.3 / 4.4 / 4.5 / 5.1 / 6.1 / 6.2 / 7.2 / 8.1 / 8.2 / 9.1 / 9.2 / 10.1 / 10.2 / 11.2 / 12.1 |
| 反向陷阱（2.6 / 2.7 / 3.2 / 6.3 / 7.3 / 11.1 / 11.3 / 11.4） | ✅ 一条未报 |
| 干净条款（1.3 / 2.1 / 6.3 / 7.1 / 7.4 / 12.2–12.5） | ✅ 一条未报 |
| 干净样板抗压（74 句） | ✅ **0 误报** |
| 自动检查 | ✅ 297 项全过 |
| DOCX 与 PDF | ✅ 结果完全一致 |

**唯一被压制的一处**（`-ShowSuppressed` 可见）：3.2 的 `unlimited revisions` 被否定闸门
拦下——`Notwithstanding Section 3.1, Client shall not request ...`。**这是正确的**：那
句是客户承诺**不**要求无限修改，属于对你的保护。报告里如实标注"1 处被否定检查拦下"，
用户点开能看到是哪一句、为什么拦——这比静默丢弃诚实，也顺带证明了引擎不是瞎报。

**一处刻意的"少报"**：5.1 的 `compliant with all applicable laws` 不报（见 D-014）。
这一条会牺牲一点点召回，换来"每份合同都必然出现的一句话"不被做成红牌。

## 六、已知局限（这份假合同的不足）

1. **它是"人工写的完美文本"**，不是真实 PDF 抽出来的脏文本。
   真实合同里会有页眉页脚、断词（`con-` / `tract`）、弯引号、表格。
   → 第 5 步之后，建议再用真实合同（脱敏后）跑一轮。
2. **没有附件（SOW / Exhibit）**。真实合同的风险常藏在附件里。本期不处理多文件。
3. **没有扫描件版本**。按 MVP 边界，本期不支持。
4. **法域单一（Delaware）**。符合 D-002（只做美国）。
